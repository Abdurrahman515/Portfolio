# Abdurrahman Baroudi — Bilingual Portfolio

A responsive, dark-themed portfolio website in Arabic and English, with complete language switching and direction changes (`RTL` / `LTR`).

## Files
- `index.html` — page structure and project content
- `styles.css` — dark visual system and responsive layouts
- `script.js` — Arabic/English translations, language switch, and mobile navigation

## Run locally
Extract the ZIP and open `index.html` in a modern browser. No package installation or build step is required. Google Fonts are loaded over the internet; system fallbacks are included.

## Publish using GitHub Pages
1. Create a repository named `portfolio` on GitHub.
2. Upload the three website files and this README to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish. Open the resulting URL on both desktop and mobile.
